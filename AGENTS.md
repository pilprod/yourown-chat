# Engineering governance discovery

Before modifying this repository:

1. Initialize the pinned policy submodules with
   `git submodule update --init .engineering-public .engineering-private`.
2. Read `.engineering-public/README.md` and every public document it lists.
3. Read `.engineering-private/AGENTS.md` and every private document it
   requires.
4. Then follow the repository instructions in `README.md`.

This file is a discovery adapter and is not an independent source of policy.
