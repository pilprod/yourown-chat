# Architecture Decision Records

Architecture Decision Records preserve the context and consequences of
owner-approved engineering decisions.

An ADR records a decision; it does not override the Engineering Constitution.
If a proposed decision requires a governance change, the Constitution is
updated through its approval process first.

Use zero-padded sequential names:

```text
0001-short-decision-title.md
```

Each record contains status, date, context, decision, and consequences.
